# JSON Safe Type

Generate TypeScript interfaces and scrub sensitive data from JSON locally.

## Features

- **Sensitive Data Scrubbing**: Automatically replaces real emails, phone numbers, and ID cards with safe dummy data.
- **Type Generation**: Automatically generates TypeScript interfaces (`RootData`) from your JSON structure.
- **100% Local & Private**: No network requests, no data tracking. All operations run entirely on your machine.

## How to use

1. Select a block of JSON text in your editor.
2. Right-click and select **"生成类型并脱敏 JSON"**.
3. The text will be instantly replaced with the generated TS interface and the scrubbed JSON data.
